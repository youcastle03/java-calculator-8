# java-calculator-precourse

## 프리코스 1주차 과제
- 애플리케이션(Application): 계산기 실행
- 계산기(Calculator): 계산 진행
- 검증기(Validator): 값 검증
- 입력 객체(InputHandler): 입력 받음
- 출력 객체(OutputHandler): 출력 받음
- 파싱 객체(Parser): 식에서 숫자 파싱

## 구현 기능 목록
- [x] 문자열을 입력 받는다.
- [x] 쉼표와 콜론 구분자로 숫자 분리 및 더하기
- [x] 커스텀 구분자 지원
- [x] 잘못된 값 입력시 `IllegalArgumentException` 발생
